# Timeline image prompt set

Generation date: 2026-08-29

Tool: built-in `imagegen`

## Production template

Each of the 75 timeline nodes was generated in an independent imagegen call. The following normalized template defined the shared art direction; the final sentence was replaced with the node-specific representation, temporal mechanism and control signal described in the matching `docs/timeline.md` card.

> Use case: scientific and educational. Asset type: one milestone illustration for a GitHub README technical timeline, landscape 16:9. Scene/backdrop: warm off-white technical-paper background with a very faint grid. Style/medium: clean premium flat-vector scientific editorial illustration, crisp geometric shapes, restrained depth, visually accurate. Composition/framing: wide, uncluttered, centered mechanism, generous margins, readable as a thumbnail. Color palette: navy, cobalt blue, cyan, charcoal, warm off-white, with one small amber accent. Text: no text, no letters, no numbers. Constraints: no logos, no watermark, no paper title, no decorative clutter. Primary request: visually explain [the node-specific representation, temporal mechanism and conditioning/control path].

## Node-specific prompt policy

- Motion-estimation nodes visualize correspondences, displacement fields or warping rather than generic “AI” imagery.
- Recurrent, autoregressive and token models visualize their actual state/token flow and causal ordering.
- GAN, VAE, diffusion, flow-matching and DiT nodes use distinct mechanism diagrams rather than interchangeable noise-to-video imagery.
- World-model nodes distinguish passive prediction, action-conditioned rollout, planning, explicit 3D reconstruction and closed-loop interaction.
- Commercial creative-model nodes visualize supported multimodal inputs and editing/output structure without imitating product logos or claiming hidden architecture.
- Every image is a conceptual mechanism illustration, not a paper figure, benchmark result or sample generated by the named model.

## File mapping

The image basename is the milestone identifier, for example `2022-flow-matching.jpg`. Every `<img>` reference in `docs/timeline.md` maps one-to-one to an image in `assets/timeline/`.
