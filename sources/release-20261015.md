## 公式跳转修复

发布后发现：直接打开 WAM 时公式正常，但从没有公式的 Coding World Model 页面即时跳转到 WAM，可能出现 MathJax 样式缓存未更新，表现为公式空白。只有容器计数与无 TeX 错误不足以验证视觉显示。

按 [Material for MkDocs 官方 MathJax 接入说明](https://github.com/squidfunk/mkdocs-material/blob/master/docs/reference/math.md)，在原有串行 typesetting 回调中先执行 `MathJax.startup.output.clearCache()`，再清理排版对象、重置 TeX 并重新排版。保留原启动顺序与所有公式正文。
