## 建议保留的结构

保留六个顶层阅读板块，不将所有内容强制整理成一棵互斥分类树。以“任务接口 → 能力 → 机制 → 系统 → 证据”构成横向主线；世界模型板块再区分表征/动力学、程序状态、视觉接口与决策闭环。JEPA 是表征预测路线，物理一致性是约束属性，视觉推理是求解与计算问题，均不应被写成 world model 必经阶段。
