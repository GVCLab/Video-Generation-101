# Timeline resource audit: nodes 51–75

Audit date: 2026-08-29. Scope: DreamerV3 through Seedance 2.5, including MiniMax H3. Only author/institution pages, papers, official repositories, official model hubs, and official product/demo surfaces are listed. A recorded video on a project page is not counted as an interactive demo. `none` means no qualifying public resource was found, not that no internal implementation exists.

## 51 — DreamerV3

- paper_or_report: https://arxiv.org/abs/2301.04104
- project: https://danijar.com/project/dreamerv3/
- code: https://github.com/danijar/dreamerv3
- weights: none
- demo: none
- notes: Author-maintained source repository; the Nature paper also names this repository as the source for the presented experiments. The repository supports saving/resuming locally trained checkpoints, but no official catalog of pretrained DreamerV3 task checkpoints was found.
